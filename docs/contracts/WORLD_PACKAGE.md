# World package v1

An `.lke-world` file is UTF-8 JSON with protocol `lke.world.v1`. It contains source workspace and world IDs and an ordered, contiguous sequence of world versions, including each version's name, description, template key, and world content. It does not contain adventure state, provider configuration, credentials, assets, or database backups. World content can itself contain private author notes or other user-entered sensitive text: inspect the package before sharing.

The local API exports and previews packages without changing canonical data. The importer validates the format, size (2 MB total and 100 KB per version's content), count (at most 100 versions), field names, version sequence, and credential-like content keys. Imported text is untrusted story data. Preview reports the source, version count, and whether the source world ID already exists; the UI also permits inspecting the full JSON. The import command creates a new world ID and preserves the version sequence in one audited, revision-checked, idempotent transaction. Source IDs and supplied package are recorded in the command history; imported versions are assigned the destination revision. Replacing an existing world is not supported.

This format is distinct from full database backup and from the planned `.lke-adventure` format. It cannot restore conversations, character records, adventure state, or images. Core unit tests cover round trips, duplicate imports, collision handling, unsupported versions, malformed sequences, secret-like keys, and size limits. API, browser, and cross-device round trips still require acceptance testing.
