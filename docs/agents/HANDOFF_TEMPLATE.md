# Enhancement handoff template

- Enhancement ID and user outcome:
- Status: proposed / authorized / implemented / verified:
- Explicit implementation scope and exclusions:
- Evidence and current source paths:
- Existing capability versus precise gap:
- Proposed journey and acceptance criteria:
- Module ownership and contract changes:
- Canon, workspace, branch, actor and time constraints:
- Source provenance, privacy and cloud consent:
- Migration, backup, rollback and asset recovery:
- Dependencies and unresolved decisions:
- Verification performed, exact results and limitations:
- Next smallest authorized action:

Do not fill unknown fields with assumptions presented as facts. A completed planning handoff does not authorize programming.
